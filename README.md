# MC Launcher

Лаунчер Minecraft: Java Edition с модами, сборками, профилями и игрой с друзьями.

## Скачать

👉 **[Последняя версия](../../releases/latest)**

| Система | Файл |
|---|---|
| Windows (установщик) | `MC-Launcher-Setup-X.Y.Z.exe` |
| Windows (без установки) | `MC-Launcher-Portable-X.Y.Z.exe` |
| Linux | `.AppImage` |

## Установка на Windows

1. Скачайте `MC-Launcher-Setup-…exe` со страницы релиза (раздел **Assets**).
2. Запустите. Если появится «Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**. Установщик не подписан платным сертификатом, это нормально.
3. Ярлык **MC Launcher** появится на рабочем столе и в меню «Пуск».

Node.js и другие программы ставить не нужно. Java для игры лаунчер скачает сам.

## Первый запуск

1. **Настройки → Аккаунты:** добавьте ник (офлайн) или войдите через Microsoft.
2. **Профили → Новый профиль:** выберите версию и, если нужны моды, загрузчик (Fabric, Forge и др.).
3. **Играть.**

## Свой сервер на компьютере — бесплатно

Вкладка **«Мой сервер»** в лаунчере:
1. Выберите версию, загрузчик и профиль с модами, примите EULA и нажмите **«Создать сервер»**, затем **«Запустить»**.
2. Выберите, как друзья будут заходить:
   - **Напрямую через интернет.** Лаунчер сам откроет порты на роутере (UPnP) и проверит, «белый» ли у вас IP. Друзьям ничего ставить не нужно.
   - **Туннель playit.gg.** Подходит, если IP «серый». Бесплатно, работает через программу playit.
   - **Radmin VPN или локальная сеть.** Друзья вступают в вашу сеть, снаружи сервер не виден.
3. Друзья вводят адрес сервера друзей на вкладке «Друзья» и нажимают **«Играть на сервере»**: версия и моды скачаются сами.
4. Пускайте игроков кнопкой «Пустить игрока» (белый список).
5. **Плагины.** Выберите тип сервера **Paper**. В разделе «Плагины» найдите нужный на Modrinth (EssentialsX, LuckPerms, WorldEdit…) и нажмите «Установить»: обязательные зависимости поставятся сами. Можно добавить и свой `.jar`. Друзьям для Paper ставить ничего не нужно.

Сервер работает, пока включён компьютер и открыт лаунчер. При закрытии лаунчера мир сохраняется, а открытые порты закрываются.

## Свой сервер (VPS)

Нужен VPS с **Ubuntu 22.04/24.04** или **Debian 12**, от 4 ГБ памяти (для модов — 6–8 ГБ). Подключитесь к нему по SSH и выполните:

```bash
curl -fsSL https://github.com/preobluka228-netizen/mc-launcher-releases/releases/latest/download/install.sh | sudo bash
```

Скрипт спросит версию, загрузчик, память и ваш ник, затем поставит Minecraft-сервер, сервер друзей с HTTPS и команду `mcctl`. В конце он покажет адрес сервера друзей: введите его в лаунчере на вкладке «Друзья». После этого на вкладке «Играть» появится кнопка **«Играть на сервере»**: лаунчер сам скачает нужную версию и моды.

Полезные команды на сервере:

| Команда | Что делает |
|---|---|
| `mcctl whitelist add Ник` | пустить игрока |
| `mcctl status` | кто онлайн |
| `mcctl mods set fabric-api,lithium` | моды сервера (их получат и игроки) |
| `mcctl mods client sodium,iris` | моды только для игроков |
| `mcctl version 1.21.4 fabric` | сменить версию (с резервной копией) |
| `mcctl backup` | резервная копия мира |
| `mcctl help` | все команды |

## Что умеет

- Любые версии Minecraft, загрузчики Fabric / Quilt / Forge / NeoForge
- Моды, ресурспаки, шейдеры и сборки с Modrinth
- Профили со своими настройками, экспорт и импорт
- Друзья, статус «в сети», приглашения на сервер: друг автоматически получает ту же версию и те же моды
- Свой сервер на компьютере (вкладка «Мой сервер»: vanilla, Paper с плагинами, Fabric, Forge, NeoForge) или на VPS одной командой; у друзей кнопка «Играть на сервере»
- Темы, акцентный цвет, свой фон

## Безопасность

Токены входа хранятся зашифрованными средствами операционной системы (на Windows — DPAPI). Пароли лаунчер не хранит: вход в Microsoft идёт через официальную страницу Microsoft.
